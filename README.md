# d4goal.com

Landing page of D4Goal (Data for Goal). Static HTML, hosted for free on GitHub Pages.

- `index.html`: the page (EN / ES / PT). Settings at the top of the script: `WEB3FORMS_KEY` and `CONTACT_EMAIL`.
- `privacy.html`: privacy policy.
- `assets/`: logo, icons, share image and self-hosted fonts (League Spartan and Figtree, SIL Open Font License).
- `CNAME`: custom domain for GitHub Pages. Do not delete.
